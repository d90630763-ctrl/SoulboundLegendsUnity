# Soulbound Legends - Version 1 Foundation

One clean Unity 6 project (6000.5.6f1). No servers inside. No art files to supply: every character, monster, weapon, building, tree, rock, effect and sky is generated by code at runtime.

## Put it into Unity Cloud Build
1. The folders `Assets/`, `Packages/`, `ProjectSettings/` must sit at the ROOT of your repository (not inside another folder).
2. Build target: Android. Unity version: 6000.5.6f1 (change `ProjectSettings/ProjectVersion.txt` if your build config uses another).
3. Nothing else to configure. The project sets itself up (Android settings, scene list, the two network prefabs) before every build. Optional: set the Pre-Export Method to `SL.EditorTools.SLEditorSetup.CloudPreExport`.
4. If the build fails, send me the first red error lines from the build log and I will fix them.

## What happens when you open the app
Loading -> one-time intro (skippable) -> account screen (Guest works now) -> character creator -> lobby -> START -> mode select (only Adventure World open) -> PLAY -> Host Village / Join by address -> the world.

## Testing multiplayer
- Phone A: PLAY -> "Host Village". Phone B (same Wi-Fi): PLAY -> type phone A's local IP address -> Join. Port 7777 (UDP).
- Each village instance holds 12 players; a new instance opens automatically when one fills. Kingdom instances hold 24 and spread players evenly.
- Dedicated server later: run the same build with `-sl-server` (or batch mode). It starts a headless server. Your own database/login replaces `ProfileStore` later.

## Controls
Left stick = move (push fully to sprint). Drag the free screen area = camera. ATTACK (hold to repeat), Heavy, Dodge, Jump, Block (hold), Interact (appears near NPCs, chests, plants, portals). 8-slot skill wheel (page button swaps to slots 9-10). Status button next to your portrait. Bag / Quests / Skills / Gear / World / Menu buttons top right.

## Game rules implemented
- Start at Level 0 in Dawnrest Village (instanced). Only Adventure World is open; modes, store, top-up locked until Level 10.
- Level 3: awaken one of ten inheritances with Elder Maren (unlocks your element's 4 skills). Up to 10 skills equipped.
- Level 10 + "Trial of Ascension" (defeat the Ancient Warden) -> Kingdom Token -> village portal -> Aurelion Kingdom (castle with walls that break, more NPC jobs and quests, stronger and more species of monsters).
- LV Up Pill (levels 1-9 only) becomes claimable once 5 players have been promoted (change `ProfileStore.PillPromotedThreshold`).
- 11 chest grades (Wood, Dark Iron, Bronze, Silver, Gold, Diamond, Emerald, Sapphire, Ruby, Mythril, Celestial). Chests are placed in the world and given as milestone rewards (with extra for the world's first).
- Not every monster drops loot; higher-level monsters drop more often and better. Herbs are scattered near the village start. Hidden quests are discovered by doing things.
- Terrain craters from big element skills; castle wall blocks break and rebuild.

## Admin guide
`Docs/ADMIN_COMPENDIUM.html` (open on your phone) lists every quest and who gives it, all NPCs, monsters with weaknesses/abilities/drops, chest grades and where every chest is, gathering nodes, equipment sources, rare materials, skills and milestones. It is generated from the game's own data. In the editor: menu Soulbound > Export Admin Compendium regenerates it.

## Code map (build order = assembly dependencies)
SL.Core (math, meshes, materials) -> SL.World (terrain, buildings, sky) + SL.Actors (characters, monsters, weapons) -> SL.Gameplay (items, quests, skills, loot, rules) -> SL.Net (server rules, players, monsters, client world) -> SL.UI (screens, HUD, panels, intro) -> SL.Game (boot and flow). SL.Editor holds the build helpers.
